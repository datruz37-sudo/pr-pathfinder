# Your first contribution

This path is designed for a first-time contributor who has found an issue labeled `good first
issue` and `help wanted`.

1. Comment on the issue with the approach you want to try.
2. Wait for assignment when the issue says coordination is required.
3. Fork and clone the repository.
4. Create a branch named after the problem, not your name.
5. Set up the environment using `CONTRIBUTING.md`.
6. Make the smallest complete change and add tests.
7. Run every documented check.
8. Open a pull request and describe evidence, trade-offs, and validation.
9. Respond to review comments with either a change or a concise technical explanation.

You do not need prior open-source experience. You do need to understand and test what you submit.
Generated filler, copied patches, fake identities, and coordinated metric inflation are not welcome.

If instructions are unclear, that is a documentation bug: open a bug report and show exactly where
you became blocked.
