# Security policy

## Supported versions

Only the latest released minor version receives security fixes while the project is in alpha.

## Reporting a vulnerability

Please do not open a public issue. Use [GitHub's private vulnerability
reporting](https://github.com/datruz37-sudo/pr-pathfinder/security/advisories/new) on the
Security tab ([how private reporting works](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)). Include affected versions, reproduction steps, impact, and any proposed mitigation.
We aim to acknowledge reports within seven days. Response times are goals, not guarantees.

## Scope

Reports about unsafe filesystem access, command execution, path traversal, malicious repository
content, and incorrect redaction are especially welcome.
